# Boss

Boss is a free, ad-free, offline-capable, mobile-first, endless leader simulation. Begin with a three-person team, then recruit specialists, support people, and lead through client work, learning, experimentation, dilemmas, and company decisions. No sign-in, tracking, external libraries, fonts or network requests are required.

**Play:** https://bsavci1.github.io/Boss/.

## How to play
Tap a person’s name on a client deal to assign or unassign them. Use Study, Teach, Experiment or Rest to guide the team. Under **Recruitment & team culture**, filter candidates by skill and personal interest, search for four candidates, and hire those you can afford. Each hire costs a one-time fee and adds $1.50/day in salaries. Interests influence performance and learning. Every person has **Recognize** (free), **Bonus** ($12), and **Coach** ($8) actions with a seven-day cooldown, plus a **Fire** button (the last employee cannot be dismissed). Team activities cost $5 per person and have a 12-day cooldown. Respond to dilemmas and combine discovered ideas into lasting breakthroughs. Choose 1x, 3x or 8x speed, Pause, or Restart. **Focus mode** suspends new client inquiries and new dilemmas without stopping progress on existing work (deadlines and salaries still apply). By default, new clients arrive only about every 12–20 game days, while dilemmas are separated by at least 45 seconds of real play. Appoint an existing employee as an **office assistant**, or hire one for $20; the assistant automatically assigns jobs to available idle staff and handles straightforward praise and family decisions. Your explicit task orders always take priority. Progress saves automatically in the browser.

## How to change the game
All the HTML, CSS and JavaScript live in one file, [index.html](index.html). Edit this complete file and commit it to `main`; GitHub Pages automatically publishes the root of `main` shortly afterward. The browser save key is `boss6` (previous `boss5` and `tl3` saves are migrated automatically), so preserve save compatibility. Also record each change in [CHANGELOG.md](CHANGELOG.md) and the Boss Notion page.

## Publishing

GitHub Pages is enabled with **Deploy from a branch → main → /(root)**. Pushing changes to `main` automatically rebuilds and publishes the site. View [deployment runs](https://github.com/BSAVCI1/Boss/actions) for status.
