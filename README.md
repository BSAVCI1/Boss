# Boss

Boss is a free, ad-free, offline-capable, mobile-first, endless leader simulation. You lead a three-person team through client work, learning, experimentation, dilemmas and company decisions. Hiring is deliberately unavailable. No sign-in, tracking, external libraries, fonts or network requests are required.

**Play:** https://bsavci1.github.io/Boss/.

## How to play
Tap a person’s name on a client deal to assign or unassign them. Use Study, Teach, Experiment or Rest to guide the team; respond to dilemmas, and combine discovered ideas into lasting breakthroughs. Choose 1x, 3x or 8x speed, Pause, or Restart. Progress saves automatically in the browser.

## How to change the game
All the HTML, CSS and JavaScript live in one file, [index.html](index.html). Edit this complete file and commit it to `main`; GitHub Pages automatically publishes the root of `main` shortly afterward. The browser save key is `tl3`, so take care with save compatibility. Also record each change in [CHANGELOG.md](CHANGELOG.md) and the Boss Notion page.

## Publishing

GitHub Pages is enabled with **Deploy from a branch → main → /(root)**. Pushing changes to `main` automatically rebuilds and publishes the site. View [deployment runs](https://github.com/BSAVCI1/Boss/actions) for status.
